# 公開前の採点の基準（案）

状態：**案（2026-11-15、Claude が書いた。本人の承認を待つ。承認の前に採点しない）**。v1.0 の順番 5「公開の準備」の (6)。

## 目的
公開する前に、初めて見る 3 種類の人の目で、README・サンプル・入れる手順を採点し、文言と「使うと止まる所」を直す。新しい機能は足さない。

## 採点する人（役）
| 役 | 想定 | 読むもの |
|---|---|---|
| 後任 | 事務職。IT の経験はない。前任者が退職した翌週に、社員から「ネットがつながらない」と言われた | サンプルの説明書（スマホ用の束の文字と、PC 用の画面の画像 3 枚）、README の「どう試すか A」 |
| 社長 | 従業員 30 人の会社。兼任の担当者が退職する。入れるかを決める | README の全体（とくに冒頭、効果の見積もり、データの扱い、作らないこと・確かめていないこと） |
| 技術者 | 初めてこのリポジトリを見る。Claude Code は使える。社長に頼まれて試す | README の全体、入れて最初の質問が出るまでの手順（README の「使ってみる」と、ヘッドレスで確かめた記録）、`plugin/` の構成、LICENSE |

- 採点する人は、毎回あたらしく作る。前の回の点も、前の指摘も、直した所も知らせない
- 渡すのは上の「読むもの」の文字と画像だけ。評価セット、正解、holdout、開発の記録は渡さない

## 採点の項目（1〜5 点。各役 5 項目、25 点満点）
点の目安：5＝迷わずできる・分かる、4＝少し迷うができる、3＝読み直せばできる、2＝一部しかできない・誤解しそう、1＝できない・誤解する

### 後任
1. 困りごと（「ネットがつながらない」「印刷できない」）から、正しいページにたどり着ける
2. そのページで、自分でやること・やってはいけないこと・連絡する相手が分かる
3. 手順の言葉と絵で、触る物（ケーブル、電源アダプター、ランプ）が分かる
4. 社員に何と返せばよいかが分かる
5. 説明書に書いていない困りごとのとき、どうすればよいかが分かる

### 社長
1. 何をする道具で、何をしないか（直さない、監視しない、本人確認しない）が分かる
2. 前任者の手間（時間、問数）と費用が分かる
3. 数字の読み方（模擬評価であること、幅、上限であること）を誤解しない
4. 安全（パスワードを集めない、外に送らない、置き場所）の説明で判断できる
5. 入れるかどうかを、追加で人に聞かずに決められる

### 技術者
1. 要るもの（Node.js、Claude Code、契約か API キー）と、試し方の違い（A・B・C）が分かる
2. 書いてある手順どおりに入れて、最初の質問まで進める（手順の抜け、古い名前、存在しないパスがない）
3. 何がどこにあり、何が AI で何がプログラムかが分かる
4. データの扱い（集めるもの、集めないもの、残る場所）が確かめられる
5. 限界と未検証の範囲が、隠れずに書いてある

## 指摘の分け方
採点する人は、点とは別に、指摘を 1 件ずつ、場所（ファイルと見出し、または画面）と引用つきで返す。Claude が次の 2 つに分ける。

| 分類 | 例 | 扱い |
|---|---|---|
| データや動作が変わるもの | 手順の中身、判定、ページの組み方、問いの数、新しい表示 | 直さない。一覧にして本人に渡す。ただし「使うと止まる」もの（書いたとおりに入れられない、コマンドが動かない）は直す |
| 文言 | 言い回し、説明の順番、足りない一言、古い名前、誤字 | 直す。サンプルの説明書の文面（AI が書いた本文）は、作り直しの対象なので直さない |

手順部品と図の文面、`verifier.md`、評価セットは、指摘があっても変えない。

## 止める決まり（2 回まで）
- 1 回目：各役 2 人ずつ採点する（同じ版を 2 人。点の差＝その役の**揺れ**）
- 文言と「使うと止まるもの」を直したあと、2 回目：各役あたらしい 2 人で採点する
- 2 回目で止める。2 回目の役ごとの平均点の伸びが揺れ以下なら、直した効果は揺れと区別できないと書く
- 直しきれなかった指摘は、README の「確かめていないこと・作らないこと」（限界）に書く
- 点を上げるために、採点の基準や読むものを途中で変えない

## 採点の道具と費用の見積もり
- API（`.env` のキー）で、Claude Opus に役を演じさせる。1 回の採点は 1 回の呼び出しで、読むものを全部渡す
- 見積もり：1 回 約 $0.3〜0.6（読むもの 2〜5 万トークン。画像は 1 役 3 枚まで）。3 役 × 2 人 × 2 回 ＝ 12 回で、約 $4〜8
- 公開の準備の予算 $15 のうち、使ったのは入れる手順の確かめなど 約 $0.1〜1（サンプルは通しを流さず $0）。超えそうなら、2 回目の前に止めて報告する

## 報告の形
- 回ごと・役ごとの点（2 人の点、平均、揺れ）
- 直した文言の一覧（場所、前、後）
- 直さなかった「データや動作が変わるもの」の一覧（本人の判断用）
- 費用
